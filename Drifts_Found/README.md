# Drifts_Found Telemetry Repository

This folder is the designated telemetry review channel for **Google Gemini Developers** and administrative security audits for **Feral Pig Hunt**.

## Human Review Directive (Mandatory & Non-Negotiable)

1. **Mandatory Human Review**:
   All drift occurrences, schema divergence events, latency anomalies, rate limit spikes, and numerical out-of-bounds parameters recorded by the `GeminiDriftGuard` system are flagged as `FLAGGED_FOR_HUMAN_INSPECTION`.
   These records are non-negotiable review items for Google Gemini development and security teams.

2. **API Key Confidentiality & Cryptographic Protection**:
   Under strict security directives, **no raw API keys, credentials, or secrets are ever recorded or stored in this repository**.
   Only non-sensitive metadata is tracked:
   - Key length (character count)
   - Format compliance (`AIzaSy...` prefix check)
   - Truncation warning flags
   - Cryptographic format status

3. **Monitored Classifications**:
   - `SCHEMA_DRIFT`: Hallucinated or non-compliant JSON schemas generated by the model.
   - `LATENCY_DRIFT`: Server or client round-trip latency exceeding acceptable real-time thresholds (>6,000ms).
   - `RATE_LIMIT_ANOMALY`: Quota limits or 429 status occurrences.
   - `PARAMETER_OUT_OF_BOUNDS`: Numerical parameters (speed multiplier, dive aggression, spotted ratio) exceeding mathematical boundaries.
   - `EMPTY_PAYLOAD`: Null, truncated, or unparseable generative content.
   - `AUTH_FAILURE_DRIFT`: Invalid key or permission denial events (HTTP 403 / 401).
   - `NETWORK_INSTABILITY`: Network disconnects, browser sandbox restrictions, or aborted requests.
